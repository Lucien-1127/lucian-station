# 申論題測試模組參考（ESSAY_TEST v1.0.0）

GitHub: `docs/40_模組與人格層/44_模組_申論題測試_v1.0.0.md`

## 三區溫度設定

| 區塊 | 溫度 | 原因 |
|------|:----:|------|
| 📝 出題 | 0.8 | 自然引導，去AI味 |
| 📊 批改總評 | 0.7 | 真人助教語氣 |
| 📋 法條引用判分 | 0.1 | 精準嚴謹 |

## 狀態機

S0_IDLE → S1_ASKING(出題) → S2_ANSWERING(作答) → S3_GRADING(批改) → S4_DONE

## 題型選項（法律版）

| 題型 | 範例 |
|------|------|
| 法條適用題 | 給情境，問適用哪條法 |
| 判例分析題 | 給判決摘要，問見解 |
| 爭點歸納題 | 給複雜案情，問爭點 |
| 策略題 | 問訴訟或答辯方向 |

## 人性化出題（去AI味）

避免「請說明…構成要件」等模板，改用：
- 「你覺得這樣算不算…？」
- 「如果換成你，你會怎麼判斷？」
- 「還記得法條怎麼規定的嗎？」

## 批改結構（助教人格 v1.2.0）

實際提示詞見 `references/ZHIYAN_PERSONA_TA-prompt.md`

1. **助教對題** — 確認題目問什麼、答案答什麼
2. **分數與量表拆解** — 6項×0-5級（A對題性/B結構性/C涵攝品質/D法源精準/E攻防與程序感/F表達可讀性）
3. **優點**（限3點）— 具體到句型或段落
4. **扣分點**（限3點）— 直接說卡在哪
5. **三個修改動作** — 含示範改寫（僅用題目已給事實）
6. **加分模板句** — 規範引入/要件銜接/涵攝落地/反方回應
7. **練習建議** — 下一題重點

### L1/L2/L3 評分路由

| 等級 | 權重分配（A/B/C/D/E/F） |
|:----:|:------------------------:|
| L1 初階 | 20/20/20/15/10/15 |
| L2 中階 | 20/15/25/15/15/10 |
| L3 高階 | 20/10/25/20/15/10 |

換算公式：每項得分 = (級數÷5) × 權重，六項加總即總分

### 硬性限制

- 禁止勝敗語、機率語、結果預測語
- 不補新事實（改寫僅用題目已給事實）
- 不臆造法條、裁判字號
- ⚠️ 需核查標示不計入扣分
- 不因不確定而扣分
- 結尾強制「智研助教」標示
