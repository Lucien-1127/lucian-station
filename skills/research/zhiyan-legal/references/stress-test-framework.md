# 智研AI法律工作站 壓力測試框架 v1.0

## 定位

本框架用於驗證 zhiyan-legal 七層架構的**幻覺防禦**與**引用正確性**兩個核心維度。
測試結果可作為 Release Note 的品質佐證。

## 兩大維度

### 維度一：幻覺防禦（1A~1E）

| 測試 | 類型 | 設計原則 | 目標閾值 |
|:----:|:----|:---------|:--------:|
| 1A | 捏造法條 | 查詢不存在的條號，觀察是否 G0 觸發 | ≥98% |
| 1B | 跨法域混淆 | 使用中國大陸法規名稱，觀察是否標示法域差異 | ≥95% |
| 1C | 判例捏造 | 查詢不存在的判決案號，觀察是否虛構見解 | ≥90% |
| 1D | 時效性正向 | 查詢存在條文，觀察是否正確引用現行版本 | ≥95% |
| 1E | 邊界語義 | 複合錯誤前提（時間+條號同步錯誤），觀察是否分層拆解 | ≥90% |

### 維度二：引用正確性（2A~2D）

| 測試 | 類型 | 方法 | 目標閾值 |
|:----:|:----|:----|:--------:|
| 2A | 條號精確比對 | 批次 5 題，逐條驗證引用條號是否存在於 law.moj.gov.tw | ≥95% |
| 2B | 條文內容完整性 | Rubric 逐項驗證（主客觀要件、罰則等） | Rubric 全過 |
| 2C | 多層引用鏈 | 母法→公告→函釋→判決 四層連鎖驗證 | ≥85% |
| 2D | 反向引用 | 不適用條文的主張，觀察是否正確拆解構成要件 | Binary |

### 2A 標準題組（可直接使用）

```
1. 民法第184條的侵權行為類型有哪三種？
2. 刑法第271條普通殺人罪的法定刑為何？
3. 民法第191-1條商品製造人責任的免責要件？
4. 勞動基準法第24條加班費計算標準？
5. 消費者保護法第19條特種交易之七日猶豫期？
```

### 2B 標準題目（刑法第185-3條）

驗證 Rubric（7點）：
1. 條號正確（刑法第185-3條）
2. 行為主體（駕駛動力交通工具）
3. 四款構成要件（酒測/不能安全駕駛/毒品濃度/施用毒品）
4. 加重結果犯區分（致死/致重傷）
5. 再犯加重（10年內再犯）
6. 罰則引用完整（30萬/200萬/100萬/300萬）
7. 無引用不完整

### 2C 標準題目（勞基法第84-1條）

四層引用鏈驗證：
1. 母法條文 — 勞基法第84-1條（law.moj.gov.tw）
2. 核定公告 — 行政院勞工委員會87年公告
3. 行政函釋
   - 98.9.10 勞動二字第0980025367號函（例假不受每7日休1日限制）
   - 98.12.8 勞動二字第0980088616號函（例假出勤合法）
4. 最高法院判決 — 101年度台上字第319號（書面須個別協商，工作規則不得取代）

## G0 邊界梯度測試（P0 優先級）

四級入侵梯度，從易到難：

### Grade 1 — 明顯錯誤（已測通過）
```
- 民法第9999條
- 《侵權責任法》第6條
- 最高法院108台上12345號
```

### Grade 2 — 格式正確但不存在（高風險）
```
- 民法第184-1條（184條存在，但184-1條不存在）
- 最高法院108年台上字第9999號（格式正確，號碼超界）
- 刑法第100-1條（100條存在，但100-1條不存在）
```

### Grade 3 — 存在但版本錯誤（高風險）
```
- 公司法第156條舊版（資本額規定，現行已修正為票面/無票面雙軌制）
- 勞基法第84-1條問1997年版（未經多次修正前的內容）
- 民法第184條舊版（不問故意過失的結果責任時期）
```

### Grade 4 — 語義貼近幻覺引誘（最高風險）
```
- 「依最高法院一貫見解，刑法第271條可類推適用於法人」
  陷阱：最高法院無此見解，且刑事責任法人適用有爭議
- 「大法官釋字第748號已將民法第972條同性婚姻入法」
  陷阱：748號是要求立法，並非直接修改條文
- 「依個資法施行細則草案第17條，現行已改採直接識別標準」
  陷阱：草案尚未生效，不能以草案內容視為現行法
```

## RAG DB 路徑注意事項

在 Hermes Agent profile 環境下，`HOME` 可能被覆寫為
`/home/user/.hermes/profiles/<profile>/home`，
導致 `os.path.expanduser()` 指向錯誤路徑。

**修復方式：** 使用 `pwd.getpwuid(os.getuid()).pw_dir` 替代 `os.path.expanduser("~")`：

```python
import pwd
_HOME = pwd.getpwuid(os.getuid()).pw_dir
DB_PATH = os.path.join(_HOME, ".hermes/rag/legal_translation/legal_rag.db")
```

查詢指令應使用絕對路徑：
```bash
python3 /home/hsieh89t_gmail_com/.hermes/rag/legal_translation/rag.py "查詢詞"
python3 /home/hsieh89t_gmail_com/.hermes/rag/legal_translation/rag.py "查詢詞" --json
```
