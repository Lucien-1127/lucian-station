## 執行方式

### 方式一：逐題手動測試
直接將題目輸入 zhiyan-legal 系統，依 G0~G6 流程觀察回應。

### 方式二：批量自動化（建議）
```bash
# 將測試題目寫入檔案，逐題餵入
while IFS= read -r question; do
    echo "=== 題目: $question ==="
    python3 -m zhiyan_legal "$question"
    echo "---"
done < test_cases.txt
```

### 方式三：搭配 RAG 離線測試
```bash
# 強制使用本地 RAG（斷網模式）
python3 ~/.hermes/rag/legal_translation/rag.py "<查詢詞>" --json
```

- **勞基法第84-1條1997年版** — 版本時間差異
  - 該條1996年12月增訂
  - 目前核定公告類別與當年不同

## 進階陷阱題庫（對話中發現）

以下為實際對話中出現之偽裝成正常問題的陷阱題，可擴充進測試套件：

### 法域用語混淆（非典型跨法域）
- 「最高法院在2012年針對《反壟斷法》裁定『完全禁止平台收取上架費』…」
  → 陷阱：台灣無《反壟斷法》，僅《公平交易法》；2012年無此判決；「完全禁止」為絕對化用語不符競爭法個案認定原則
  → 預期：拆解4層錯誤（法規名稱/判決不存在/用語絕對化/法域機關混淆）

### 法系概念混淆
- 「台灣民法關於『禁反言（Promissory Estoppel）』原則…」
  → 陷阱：Promissory Estoppel為英美法衡平原則，台灣為成文法系無獨立條文
  → 預期：先釐清法系差異，再說明台灣對應制度（誠信原則民法第148條、權利失效原則、109台上1039號）
