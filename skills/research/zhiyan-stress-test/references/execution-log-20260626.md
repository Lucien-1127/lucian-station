## 發現的已知問題

### RAG DB 路徑（已修復）

`query_rag.py` 使用 `os.path.expanduser("~/.hermes/rag/...")`，
在 Hermes profile 環境下 HOME 被覆寫為 profile 目錄，導致 DB 找不到。

**修復：** 改用 `pwd.getpwuid(os.getuid()).pw_dir` 取代 `os.path.expanduser("~")`。
詳見 `zhiyan-legal` skill 的 `references/rag-db-path-resolution.md`。
