## 目錄結構

```
├── vm/           # VM 系統配置快照
│   ├── system.txt      # OS、核心、硬體、記憶體、磁碟
│   ├── packages.txt    # 已安裝套件清單
│   ├── network.txt     # 網路介面與路由
│   ├── services.txt    # 執行中服務
│   ├── docker.txt      # Docker 版本與資訊
│   ├── hermes-config.txt # Hermes Agent 配置
│   ├── cron.txt        # Cron 排程
│   └── disk.txt        # 磁碟分割配置
├── skills/       # Hermes 技能備份
│   ├── backup/         # 完整技能 SKILL.md 備份（依類別/名稱）
│   ├── scripts/        # Hermes 腳本備份
│   └── inventory.txt   # 技能清單
├── logs/         # 日常運作紀錄
│   └── YYYY-MM-DD.md   # 每日操作紀錄
└── AGENTS.md     # Lucian 磐石矩陣提示詞
```
